# Python Utility Functions for Data Processing

**Student:** Raeed Saud Alotaibi  
**Program:** Tuwaiq Academy

A set of hands-on Python activities that turn repeated code into clean, reusable functions for working with data.

## What's inside

| Activity | Description |
|----------|-------------|
| 1. Refactoring | Replaced repeated statistics code with one reusable function. |
| 2. Utility library | Built reusable functions: `calculate_statistics`, `normalize_data` (min-max), `remove_outliers`, `train_test_split`, and `encode_labels`. |
| 3. Data cleaning with pandas | Used `lambda` and `.apply()` to clean prices, fill missing values, create a total column, and categorize products into low / med / high. |

## Files

- `assignment.ipynb` — the activities with their outputs.
- `assignment.py` — the same code as a plain Python script.

## Run

```bash
pip install pandas
python assignment.py
```
